# LOMAssistant 3.0.9-ko.3 — AI 채팅 입력·조회 결과 한국어 전환

원본 v3.0.9와 공식 한국어 게임 `release_1.0.6001.0` 기준 로컬 검증판입니다. GitHub 공개 릴리스는 아직 만들지 않았습니다.

## 변경 사항

- 공략 도우미의 지시문과 히로인 9명·당포의의 인물 설정을 한국어로 구성합니다. 기존 공식 한국어 대사 기반 호칭·자칭·말투와 현재 회차에서 읽은 대사 예시를 함께 적용합니다.
- 15개 도구의 용도와 매개변수 설명, 임무·분기·플래그·물품·상점·문파·이벤트 조회 안내, 관계·현재 화면 설명을 한국어로 제공합니다. 기존 조건 자료와 이름은 필요한 곳에서 기존 검수 번역표를 함께 사용합니다.
- 한국어 호감도·수치 이름으로 역검색과 경로 정렬을 지원합니다. 도감 번호를 묻는 `생사부 3번`, `결말 4`도 인식합니다.
- 긴 대화 요약·심층 모드·조회 횟수 소진 안내도 한국어로 구성합니다. 이전 AI 답변의 수치나 결론을 사실로 기억하지 않는 요약 규칙을 유지합니다.
- AI 탭의 상태·오류·조회 기록·수정 카드 문구를 한국어로 생성합니다. 새 `【공략 힌트】`와 기존 대화의 중국어 힌트 구분자를 모두 읽습니다. 표정 ID와 기존 저장 형식은 유지합니다.
- 경로 합산이 한국어 표시 효과를 다시 분석하던 부분을 수정했습니다. 합산은 원본 효과로 수행하고 한국어 이름은 결과 표시와 검색어 대응에 사용합니다. 배타적인 분기·부호·정렬·최대/최소 판정은 유지합니다.
- 화면 비율·배치·고정 크기·글꼴·여백·색상 설정을 유지합니다. AI 탭도 ko.1 배치 비교 검사에 포함했습니다.

도구 이름·JSON 키·필수 매개변수·전송 형식·요청 제한·재시도 횟수는 유지합니다. 수치나 설정은 기존처럼 카드에서 확인해야 적용됩니다. 모델의 답을 재번역하기 위한 추가 API 호출은 넣지 않았습니다.

## 적용

1. 게임을 완전히 종료하고 기존 `BepInEx/plugins/LOMAssistant/LOMAssistant.dll`과 `event-names-ko.tsv`를 게임 폴더 밖에 백업합니다.
2. ZIP의 `BepInEx` 폴더를 게임 설치 폴더에 덮어씁니다. DLL 두 버전을 다른 이름으로 함께 넣지 마세요.
3. 게임과 모드 표시 언어를 한국어로 설정하고 재실행합니다.
4. AI 탭에서 **새 대화**로 확인합니다. 기존 대화는 유지되지만 이전 혼합 답변이 대화 기록으로 다시 전달될 수 있습니다.

BepInEx 6·Newtonsoft.Json 환경은 ko.1/ko.2와 같습니다. 빌드·검사·패키징은 게임 설치 폴더·설정·저장을 수정하지 않습니다.

## 실제로 확인할 항목

1. **공략 도우미:** 선택지나 주사위 화면에서 「여기서 어떻게 선택하면 돼?」를 묻고, 조회 후 한국어로 현재 선택지·조건·결과를 설명하는지 확인합니다.
2. **인물 대화:** 다른 히로인이나 대사형에게 인사한 뒤 공략을 질문합니다. 호칭·자칭·표정과 별도 공략 힌트가 맞는지, 일상 대화에 불필요한 힌트가 붙지 않는지 확인합니다. 힌트 끄기·스포일러 제한도 확인합니다.
3. **경로와 검색:** 「이 임무에서 욱죽 호감도를 가장 많이 올리는 경로는?」, 「심상 판정은 어디 있어?」 등을 묻고 실제 조회한 경로별 결과를 쓰는지 확인합니다.
4. **변경 카드:** 원하는 수치 변경을 제안받아 먼저 거절했을 때 값이 유지되는지 확인합니다. 적용할 변경만 확인합니다.
5. **기존 대화:** 지난 대화를 열었을 때 공략 힌트가 별도 칸에 표시되고 첫 글자가 잘리지 않는지 확인합니다. 긴 대화의 자동 요약 이후 한국어가 유지되는지는 해당 시점에 확인합니다.

외부 AI를 호출하는 질문과 연결 테스트에는 선택한 제공업체의 기존 요금 체계가 적용됩니다.

## 검증 및 남은 범위

빌드·자동 검사 **8,882건 통과**. 실제 소스의 도구 스키마·경로 계산·카드 제안/확인 함수를 오프라인 게임 대체 자료로 실행했습니다. 원본과 한국어 경로의 최대/최소·부호·배타성, JSON 구조 보존, 확인 전 미적용·거절·중복 적용 방지를 확인했습니다. API 전송 구현과 스토리 분석·대사 열람·스포일러 제한 코드는 ko.2와 비교했습니다.

실제 외부 AI 생성과 게임에서의 이번 패치 작동은 아직 확인하지 않았습니다. 기존 게임 자료의 미번역·외부 제공업체의 원문 오류·이전 대화 내용은 여전히 다른 언어를 포함할 수 있으며, 모든 모델의 중국어 혼입이 사라진다는 보장은 아닙니다. 설정·저장 화면의 후속 전환과 F9 전체 설명의 한중 혼합 47건은 남아 있습니다.
