# LOMAssistant 한국어 개선판 3.0.6-ko.4

원본 LOMAssistant 3.0.6 / 게임 1.0.6001 기준의 랜덤 이벤트명 수정판입니다. 3.0.6-ko.3까지의 수정 사항을 포함합니다.

## 수정 사항

이동할 때 지옥도·아귀도와 관계없는 이벤트에도 「지옥도 귀졸의 길막」「아귀도 해적의 길막」 같은 이름이 표시되던 문제를 수정했습니다.

게임이 여러 이벤트 목록에서 `Travel_F_01` 등의 ID를 재사용하는데, 기존 한글화는 ID 하나로 표시 이름을 정했습니다. 그 결과 다른 이동 이벤트에 무림대회 이동 경로의 이름이 붙었습니다. 이제 **이벤트 ID와 중국어 개발자 이름이 모두 일치해야** 번역을 적용합니다.

- 문맥이 다른 이름 9개를 보충했습니다. 총 397개 ID에 대해 문맥별 번역 406개를 제공합니다.
- 게임에서 추출한 이벤트 객체 433개 모두가 해당 ID·원문 이름의 번역과 연결되는지 확인했습니다.
- 번역 후보 내보내기와 패키징 검사도 ID·원문 이름의 조합을 구분하도록 수정했습니다.
- 선택 버튼의 순서, 이벤트 선택·추첨, 확률, 게임 수치와 저장 동작은 변경하지 않았습니다.

## 설치 및 확인

1. 게임을 종료하고 기존 `BepInEx/plugins/LOMAssistant/LOMAssistant.dll`과 `event-names-ko.tsv`를 게임 폴더 밖에 백업합니다.
2. `LOMAssistant-3.0.6-ko.4-patch.zip`의 `BepInEx` 폴더를 게임 설치 폴더에 덮어씁니다. **DLL과 번역표를 함께 교체**해야 합니다.
3. 게임을 다시 실행하고, 문제가 났던 지역 이동의 이벤트 이름을 확인합니다. 구버전 DLL을 다른 이름으로 플러그인 폴더에 남기지 마세요.

원본 LOMAssistant 3.0.6과 BepInEx 6이 필요합니다. 이미 3.0.6-ko.1/ko.2/ko.3을 사용 중이면 이 패치만 적용할 수 있습니다. 설정·저장 파일은 교체하지 않습니다.

## 확인한 범위

- 자동 검사 3,528건 통과. 같은 ID를 쓰는 일반 이동과 실제 지옥도·아귀도 조우를 서로 다른 이름으로 찾는지 검사했습니다.
- 실제 게임 데이터의 이벤트 객체 433개와 번역표의 문맥을 대조해 누락 0건을 확인했습니다.
- 내장 조건의 중국어 잔여 0건, 플래그 표시 조합 5,304건 실패 0건, 수집 조건 5,060건의 중국어 잔여 0건입니다.
- 수정본을 게임에서 실행해 해당 이동 장면을 확인하는 검증은 수행하지 않았습니다. AI 말투 추가 작업은 이번 수정에 포함하지 않습니다.

설치 ZIP에는 DLL, 문맥별 이벤트명 번역표, 이 안내와 `release-info.json`이 포함됩니다. BepInEx·Newtonsoft.Json은 포함하지 않습니다.
