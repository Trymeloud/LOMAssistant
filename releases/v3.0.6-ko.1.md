# LOMAssistant 한국어 개선판 3.0.6-ko.1

원본 [LOMAssistant v3.0.6](https://github.com/kevinnie2003/LOMAssistant/releases/tag/v3.0.6)에 기존 2.9.3-ko.1의 한국어 개선을 옮긴 비공식 패치입니다. 게임 **1.0.6001 / 공식 한국어**를 기준으로 빌드했습니다.

## 설치

설치 파일은 **`LOMAssistant-3.0.6-ko.1-patch.zip`**입니다. `Source code` 파일은 설치용이 아닙니다.

1. 게임을 종료하고 기존 `BepInEx/plugins/LOMAssistant/LOMAssistant.dll`과 `event-names-ko.tsv`를 게임 폴더 밖에 백업합니다.
2. 게임을 1.0.6001로 업데이트하고, [원본 3.0.6](https://github.com/kevinnie2003/LOMAssistant/releases/tag/v3.0.6)을 설치·업데이트합니다. 기존 2.9.3-ko.1 사용자는 원본 업데이트를 먼저 진행하세요.
3. 이 패치 ZIP의 `BepInEx` 폴더를 게임 설치 폴더에 덮어씁니다.
4. `LOMAssistant.dll`과 `event-names-ko.tsv`가 같은 플러그인 폴더에 있는지 확인하고, 한국어로 게임을 실행합니다.

이 ZIP에는 BepInEx와 Newtonsoft.Json이 포함되어 있지 않습니다. 구버전 DLL을 다른 이름으로 플러그인 폴더에 남겨 두지 마세요. 설정·저장 파일은 교체하지 않습니다. 최신 게임에서 문제가 생기면 우선 원본 **3.0.6 DLL**로 복구하세요. 게임 1.0.6001에서 구버전 2.9.3 DLL의 호환성은 보장하지 않습니다.

원본 설치 프로그램이나 내장 업데이트 안내로 다시 업데이트하면 한국어 개선 DLL도 원본으로 교체될 수 있습니다. 이후 한국어 개선판은 이 포크의 릴리스를 확인하세요.

## 변경 사항

- 3.0.6의 새 회상 기록·퀵세이브·분기 저장 대응, AI 동행, 저장 시간 및 방문 표시 수정 등을 반영했습니다.
- 기존 플래그·조건·인물명·임무명 번역과 랜덤 이벤트명 397개를 유지했습니다.
- 새 조건 데이터에서 누락된 조건명 4개와 호전차 판정 주석을 번역했습니다. 「미세 골절」은 게임의 한국어 표기를 사용했습니다.
- AI의 물품·상점·문파·사용 지점 조회 안내를 번역하고, 답변이 출력되는 동안 공략 힌트 제목이 중국어로 나오는 부분을 보완했습니다.
- 분기 저장 안내를 3.0.5 이후의 자동 저장 기준에 맞추고, UI 숨기기 복원 키 안내를 갱신했습니다.
- 앞서 취소한 흐름도·수집 현황·진행 경로의 UI 재설계는 포함하지 않습니다.

## 확인한 범위

- 게임 `release_1.0.6001.0`의 어셈블리를 참조해 빌드 성공.
- 자동 번역 검사 **3,103건 통과**, 3.0.6 내장 조건의 중국어 잔여 **0건**.
- 현재 게임에서 플래그 1,069개를 다시 추출해 표시 조합 **5,304건 검사, 실패 0건**.
- 기존 실행에서 수집한 조건 5,054건을 재검사해 중국어 잔여 0건. 이 캐시 검사는 새 버전에서 게임을 실행한 검증이 아닙니다.
- F9 플래그 전체 설명의 한중 혼합 표기 **47건은 기존과 같이 남아 있습니다**. 일부 제목·문구에도 미번역이 남을 수 있습니다.
- 게임 안의 화면·저장·회상 동작과 실제 AI 서비스 연결은 아직 검증하지 않았습니다. AI 답변 자체는 외부 모델이 생성하며 번역표로 보장되는 영역이 아닙니다.

자세한 비교 범위는 저장소의 `reports/compatibility-3.0.6-ko.1.md`를 참고하세요. ZIP에는 DLL, 이벤트 번역표, 이 설치 안내와 `release-info.json`이 포함되며, 별도 `SHA256SUMS.txt`로 ZIP의 해시를 확인할 수 있습니다.
