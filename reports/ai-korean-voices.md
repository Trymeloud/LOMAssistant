# AI 인물 말투의 공식 한국어 대사 대조

대조일: 2026-10-28. 설치된 게임 `release_1.0.6001.0`의 공식 한국어 데이터를 참고했다.

후속 적용(2026-10-29): ko.3에서는 아래 공식 대사 기반 말투 규칙을 유지하면서 모든 인물의 배경 설정과 대화 지시문도 한국어로 구성했다. 기존 설정의 한국어 번역과 공식 대사에서 확인한 호칭·말투는 구분한다. [전환·검증 내역](korean-ai-3.0.9-ko.3.md).

## 자료와 적용 범위

- `level0`의 `LeanLanguageCSV`에서 언어가 `Korean`인 항목과 연결된 `sharedassets0.assets`의 대사 표를 식별했다. 대사 표의 파일명만으로 언어를 추측하지 않았다.
- `resources.assets`의 스크립트에서 `setcharacter`와 `say(GetStoryText(...))`를 읽어 화자를 구분했다. 열 인물에 속한 대사 키 18,083개를 분류한 뒤, 호칭·자칭이 나타나는 공식 번역을 대조했다. 모든 대사를 수동 검수했다는 의미는 아니다.
- 아래 호칭과 자칭은 공식 번역에서 확인한 표현이다. 말투 지침은 확인한 대사와 기존 인물 설정을 요약한 편집 내용이며, 공식 문장을 그대로 재배포하는 자료는 아니다.
- 게임의 대사 전문은 패치에 넣지 않는다. 실행 중 참고 예시는 플레이어가 이미 읽었고 이번 저장의 스토리 기록과 연결되는 대사에서 가져온다.

## 대조 예시

| 인물 | 확인한 호칭·자칭과 어조 | 대사 키 예시 |
|---|---|---|
| 소사매 | 사형, 짧고 담백한 말, 토닥토닥 | `D_3_16_2_003`, `D_4_9_3_4_021` |
| 서행 | 조 군, 신첩, 본궁. 공손한 어조와 위엄 있는 어조를 문맥에 따라 구분 | `D_4_8_10_1_001`, `D_3_8_4_1_002`, `D_Birth_01_01_025` |
| 엽운상 | 조 오라버니, 오라버니, 자칭 상아. 장난과 응석을 자연스러운 한국어로 표현 | `D_S0018_03_042`, `D_2_4_8_2_032`, `D_S0205_01_076` |
| 용상 | 조 동생, 동생, 누나. 시원시원하고 솔직한 어조 | `D_S0022_01_051`, `D_S0021_01_002` |
| 우소매 | 아활, 본매. 활기차고 자신만만한 말투 | `D_4_8_6_147`, `D_6_10_1_part_2_012` |
| 하후란 | 제자야, 스승. 짧고 단호하게 말하는 어조 | `D_S2200_02_079`, `D_S0802_02_Break_01_008` |
| 욱죽 | 조활, 나. 소박하고 직설적이며 당황할 때의 짧은 더듬음 | `D_7_3_2_5_035`, `D_6_4_4_1_190` |
| 위국 | 조 사형, 조 공자, 소녀. 관계에 따라 소첩 등으로 달라짐 | `D_Talk_Girl5_02_059`, `D_3_2_2_155`, `D_3_2_2_127` |
| 상관형 | 조활, 나. 언니 자칭은 여동생 등을 대하는 장면의 표현 | `D_6_5_2_Break_01_102`, `D_7_5_6_3_006` |
| 당포의 | 사제, 대사형. 능청스러운 농담과 사제를 챙기는 어조 | `D_4_8_6_055`, `D_8_6_3_2_136` |

특히 이전 개발판에서 엽운상의 `裳儿`를 일반적인 이름 표현으로 안내했던 부분을 공식 번역의 **상아**로 바로잡았다. `本梅`는 **본매**, 서행의 `妾身`은 **신첩**으로 구분했다. 위국과 하후란에게 같은 자칭을 일률적으로 적용하지 않는다.

## 관계와 진행도

한국어 표시 상태에서는 중국어 `Calls`만 검색하던 경로 대신, 공식 번역의 한국어 호칭을 찾는다. 다른 회차의 열람 기록에서 호칭을 가져오지 않도록 이번 저장의 스토리 기록에 연결된 스크립트를 대상으로 한다.

`조랑`, `서방님`, `낭군` 등의 친밀한 호칭은 해당 인물과의 인연 진행 완료가 확인된 경우에만 검색한다. 단순히 마음에 둔 사람으로 설정한 것만으로 인연 진행이 끝났다고 취급하지 않는다. 확인된 최근 호칭이 없으면 기본 호칭을 사용한다.

문자열 일부를 잘못 읽는 경우도 제외한다. 예를 들어 소사매의 `사형`을 `대사형`에서 찾지 않으며, `낭군감`을 조활에게 쓰는 직접 호칭으로 해석하지 않는다.

## 검증 한계

프로필 연결, 한국어 호칭 인식, 인연 완료 전·후 구분, 단어 경계, 다른 언어의 프롬프트 보존은 자동 검사한다. 실제 외부 AI 서비스의 답변을 생성하는 검증은 수행하지 않았다. 지침이 모델의 자연스러운 말투나 중국어 혼입 방지를 완전히 보장하지는 않는다.
