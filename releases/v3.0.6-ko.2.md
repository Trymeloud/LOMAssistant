# LOMAssistant 한국어 개선판 3.0.6-ko.2

원본 LOMAssistant 3.0.6 / 게임 1.0.6001의 공식 한국어를 기준으로 한 수정판입니다. 3.0.6-ko.1의 한글화를 유지하면서 흐름도 조건에 남는 중국어를 수정했습니다.

## 수정 사항

- 흐름도 연결선의 「그 외」 조건을 중국어 원문 18글자로 자른 뒤 번역하던 문제를 수정했습니다. 이제 온전한 조건명을 먼저 번역하고, 번역된 한국어를 기존 길이로 축약합니다.
- 소사매 호감도·공동파 전투·금오상인 결투 조건이 섞여 나오는 사례로 확인했습니다. 자세한 조건에는 비교값과 플래그 ID를 유지합니다.
- 실제 실행에서 새로 수집된 「우소매 또는 욱죽을 받아들임」 조건의 중국어 식별자 표기를 보완했습니다.
- 내장 분기 조건의 축약 표시도 중국어 잔여 검사에 포함했습니다. 실제 수집 조건 검사에서 실패가 발생하면 검사 명령도 실패하도록 보완했습니다.

조건 판정·플래그 값·경로 계산과 화면 배치는 변경하지 않았습니다. 앞서 취소한 UI 재설계는 포함하지 않습니다.

## 설치

설치 파일은 **`LOMAssistant-3.0.6-ko.2-patch.zip`**입니다.

1. 게임을 종료합니다.
2. 기존 `BepInEx/plugins/LOMAssistant/LOMAssistant.dll`과 `event-names-ko.tsv`를 게임 폴더 밖에 백업합니다.
3. 게임 1.0.6001과 [원본 LOMAssistant 3.0.6](https://github.com/kevinnie2003/LOMAssistant/releases/tag/v3.0.6)이 설치되어 있어야 합니다. **이미 3.0.6-ko.1을 사용 중이면 원본을 다시 설치할 필요 없이 이 패치만 적용합니다.**
4. ZIP의 `BepInEx` 폴더를 게임 설치 폴더에 덮어쓰고 다시 실행합니다.

DLL과 이벤트명 번역표는 같은 플러그인 폴더에 있어야 합니다. 구버전 DLL을 다른 이름으로 플러그인 폴더에 남기지 마세요. BepInEx·Newtonsoft.Json은 이 ZIP에 포함하지 않습니다. 설정과 저장 파일은 교체하지 않습니다.

## 확인한 범위

- 게임 `release_1.0.6001.0`의 어셈블리를 참조한 빌드 성공.
- 번역 검사 **3,108건 통과**. 화면에 나온 조건의 축약·전체 표시, 비교값·플래그 ID 보존을 검사했습니다.
- 3.0.6 내장 조건 및 흐름도 분기 조건의 축약 표시에서 중국어 잔여 **0건**.
- 플래그 표시 조합 **5,304건, 실패 0건**. 현재 실행에서 수집된 조건 **5,060건, 중국어 잔여 0건**.
- 수정 DLL을 게임에서 실행해 화면을 확인하는 검증은 수행하지 않았습니다. F9 전체 설명의 기존 한중 혼합 47건과 일부 문구의 미번역은 남아 있습니다.

ZIP에는 DLL, 이벤트명 번역표 397개, 이 설치 안내와 `release-info.json`이 들어 있습니다. 별도 `SHA256SUMS.txt`로 ZIP의 해시를 확인할 수 있습니다.
