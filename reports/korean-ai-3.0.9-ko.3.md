# AI 채팅 한국어 구성 전환 검증

대상: `3.0.9-ko.3`, 원본 v3.0.9 / 공식 한국어 게임 `release_1.0.6001.0`. 검증일: 2026-10-29.

## 원인과 변경 경계

기존에는 한국어 응답 규칙을 붙인 뒤에도 중국어 시스템 지시문·인물 배경·도구 설명·조회 문구·요약 지시문을 모델에 전달했다. 이번에는 한국어일 때 공략 도우미·인물의 프롬프트를 별도로 구성하고, 도구 스키마의 설명만 복제·교체한다. 조회 안내는 생성 지점에서 한국어 문구를 고른다. 완성된 AI 답변에 문자열 치환을 반복하거나 번역용 API를 추가 호출하지 않는다.

`KoreanAiPrompt`의 배경 설명은 원본 인물 설정을 한국어로 요약·번역한 것이다. 공식 한국어 대사를 새로 모두 검수했다는 뜻은 아니다. 기존 `AiKoreanVoice`의 공식 대사 대조 결과와 현재 회차에서 읽은 대사 예시를 함께 쓴다. 게임 대사 전문은 배포하지 않는다. [기존 대조 자료](ai-korean-voices.md).

게임에서 오는 한국어 대사·이름을 우선하며, 원본 조건 템플릿과 수치명 등에는 기존 검수 번역표를 호환 경계로 사용한다. 모든 동적 게임 문장을 이번에 새로 구현한 것은 아니다. 알려지지 않은 자료를 임의로 지우지 않는다.

## 계산과 프로토콜

- `StoryScript.CanonicalEffectsOn`으로 원본 효과를 조회한다. `AiAnalysis.Routes`는 이 결과를 기존 숫자 정규식으로 읽어 경로별 합계를 만든다. 화면용 효과·번역된 이름은 합산 키로 사용하지 않는다.
- 한국어 focus/역검색은 표시 이름을 원본 키에 대응시키며, 합산한 값을 다시 계산하거나 분기를 합치지 않는다. 호감도 접두·접미 표현과 띄어쓰기를 지원한다.
- 도구 15개의 이름, JSON 프로퍼티, type/required/items와 선택 매개변수는 유지한다. 한국어 스키마는 DeepClone 후 description만 바꾸며 원본은 변경하지 않는다.
- 제안은 실행 콜백을 카드에 담을 뿐이다. 사용자가 확인할 때만 기존 Resolve에서 실행하며 거절·만료·이미 처리된 카드는 실행하지 않는다.
- API 주소·모델 기본값·전송 본문 작성·재시도·제한·토큰 예산은 바꾸지 않았다.
- 기존 중국어 힌트와 새 한국어 힌트는 길이가 다르므로 실제 구분자의 길이로 잘라 표시한다. 스트리밍·대화 내보내기도 둘 다 인식한다.

## 자동 검증

빌드와 전체 검사 **8,882건 통과**. 기존 빌드 경고 CS0649·CS0414 두 건 외 추가 오류 없음.

- 10개 인물의 배경·호칭·힌트 켜기/끄기·스포일러 3단계 지시문, 요약·심층 지시문과 명시적 한국어 문구의 한자 잔여 및 서식 인자를 검사했다. 중국어 이름 대응표 등 의도적인 원문과 동적 게임 자료 전체가 검사에서 0이라는 뜻은 아니다.
- 실제 `CanonicalTools`와 `Schema`를 테스트용 어셈블리에서 실행하여 한국어 스키마와 설명 외 구조가 동일하고 원본이 수정되지 않는지 검사했다.
- 실제 `Routes`, `StoryScript` 효과 조회, `Propose`, `Resolve`를 소스에서 추출·컴파일해 게임 대체 자료로 실행했다. 한국어 화면 효과를 의도적으로 +999로 넣어도 원본 +3으로 계산하는지, 호감도 두 분기의 최대 +7/최소 -5와 다른 수치 합계가 유지되는지 확인했다.
- 수정 전 미적용, 거절, 확인 후 1회만 적용, 실행 콜백이 없는 예전 카드의 미적용을 확인했다. 실제 게임의 모든 수치 행을 실행한 테스트는 아니다.
- 전송 구현은 한국어 문구 선택을 제거한 뒤 ko.2(`c381992`)와 토큰 단위로 비교했다. 스토리 Parse·사용 지점 Build/조건 분석, 대사 열람·인연 완료·인물지 제한·최근 호칭/회차 정렬 함수도 비교했다.
- AI 탭을 포함한 좌표·스타일·배율·폭/높이·여백 표현식은 사용자 승인 ko.1과 같았다. 기존 문구에 따른 자동 줄바꿈과 글자 폭 계산은 유지한다.
- 기존 회귀 검사: 임무 메타데이터 511개 이름 후보, 플래그 표시 5,304조합, 실제 수집 조건 5,060개 통과. F9 전체 설명의 한중 혼합 47건은 이번 범위 밖이다.

검사 명령:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build-ko.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tools/ko-check/run.ps1 -GameFlags bin/ko-check/game-flags-3.0.6.json -LiveConditions 'C:/Program Files (x86)/Steam/steamapps/common/LegendOfMortal/BepInEx/plugins/LOMAssistant/StoryReview/conditions.json' -ModAssembly bin/LOMAssistant.dll
```

실제 외부 AI 호출·게임 설치 파일 교체·실제 플레이 검증은 수행하지 않았다. 사용자 확인은 [릴리스 안내](../releases/v3.0.9-ko.3.md)의 새 대화부터 진행한다. 기존 기록은 보존하고, 과거의 혼합 답변이 새 프롬프트와 함께 다시 전달될 수 있음을 구분한다.
