# 한국어 전환 진행 상황과 남은 작업

정리일: 2026-10-30. 개발 브랜치: `korean-native-3.2.1`. 공개 사전 배포판: **3.2.1-ko.3**.

3.2.1 원작 한국어 보완의 대조와 통합 범위는 [통합 보고서](upstream-3.2.1-korean-review.md), 적용 후 확인 항목은 [통합판 안내](../releases/v3.2.1-ko.3.md)를 참고한다. 새 점프 실행·실제 게임 캐시 로딩·외부 AI 응답은 아직 확인하지 않았다.

사용자의 「잘 됨」「저거 됐음」은 각 패치 적용 후 작동 확인으로 기록한다. 모든 스토리·저장 상황·외부 AI 응답을 개별 검증했다고 확대하지 않는다. 자동 검사 수도 전체 UI의 완전한 한국어화를 뜻하지 않는다.

## 남은 작업과 권장 순서

### 1. AI 채팅 전환 완료 — 실제 모델·게임 확인 남음

아래 구현은 ko.3에서 완료했다. 전환 범위와 오프라인 검증은 [AI 전환 보고서](korean-ai-3.0.9-ko.3.md), 실제 확인 순서는 [ko.3 안내](../releases/v3.0.9-ko.3.md)에 기록했다. 알려지지 않은 동적 게임 자료와 이전 대화까지 모두 한국어라는 뜻은 아니다.

- 공략 도우미의 시스템 지시문, 인물별 배경·성격 설명, 관계·현재 상황 설명을 한국어로 구성한다. 기존 공식 한국어 호칭·자칭·관계 단계 규칙은 유지한다.
- 도구 설명과 스토리·플래그·임무·물품·이벤트 조회 결과를 한국어로 제공한다. 자료의 ID와 수치, 스포일러 범위를 보존한다.
- 긴 대화의 기억 요약과 심층 모드 등 보조 지시문도 전환했다. 한국어에서는 별도 한국어 지시문을 사용한다.
- AI 탭의 상태·오류·변경 제안 카드 등 표시 문구도 확인한다.
- 도구 이름·JSON 매개변수 키·API 형식은 유지하고, 수치·설정 변경은 기존 사용자 확인 카드를 거치게 한다.

주요 파일: `AiChat.cs`, `AiPersonas.cs`, `AiKnowledge.cs`, `AiAnalysis.cs`, `AiItems.cs`, `StoryReviewPanel.Ai.cs`. `AiReplyLanguage.cs`/`AiKoreanVoice.cs`의 기존 개선도 함께 유지한다.

확인 기준: 새 대화의 공략 답변과 인물별 말투·표정, 자료 조회 뒤 답변, 긴 대화 요약 이후 답변을 구분해 확인한다. 자동 검사와 실제 모델의 응답 검증은 별도로 기록한다. 전환만으로 모든 모델의 중국어 생성이 완전히 사라진다고 보장하지 않는다.

### 2. 설정·저장·나머지 안내 화면 전환

2026-10-30 ko.2 전체 점검에서 [실제 조합 누락](chinese-composition-audit-3.2.1-ko.2.md)을 확인했고, 해당 6개 영역은 ko.3에서 수정했다. 분기 목적지·결투 가로 표시·비급 보너스·설정/물품 경고·퀵세이브 메모·턴 넘기기 대사의 대상 15개 조합은 중국어 잔여 0건이다. 이 결과는 나머지 동적 게임 자료와 모든 화면의 완전한 전환을 뜻하지 않는다. F9 전체 설명 47건과 나머지 설정·저장 화면 구조 전환은 계속 남아 있다.

- 설정 이름·설명·선택 항목·재시작 안내와 프리셋 설명을 한국어 문구 키로 제공한다.
- 저장/불러오기 목록·상세, 노드 저장·퀵세이브, 수치 프리셋의 알림·확인·오류 문구를 전환한다.
- 검색·변경 확인·실패 메시지와 공용 안내의 남은 중국어 문장 조립을 점검한다.

주요 파일: `StoryReviewPanel.Settings.cs`, `StoryReviewPanel.Presets.cs`, `StoryReviewPanel.StatPresets.cs`, `StoryReviewPanel.Anytime.cs`, `SaveBrowser.cs`, `UiDescriptions.cs` 등.

확인 기준: 화면 배치를 유지하면서 이름·값·설명이 일치하고, 설정 저장·재시작 표시·저장/불러오기·삭제 확인이 기존대로 동작해야 한다. 설정 키·값·저장 형식은 바꾸지 않는다. 내부에서 재시작 여부 등을 판단하는 원본 설명과 화면용 설명을 분리한다.

### 3. F9 플래그 전체 설명의 한중 혼합 47건 정리

- 기존 번역이 있으나 전체 설명 조회에 적용되지 않는 44건의 공백·줄바꿈·조회 순서를 수정한다.
- 전체 값별 설명이 빠진 3건(`M30052`, `M80006`, `M80011`)은 게임 데이터·스크립트와 대조해 번역한다.
- 첫 줄 이름만이 아니라 각 값의 의미까지 검사한다. 원래 설명이 없는 185개에 임의 설명을 만들지 않는다.

확인 기준: 전체 설명의 중국어 잔여 0건과 함께 플래그 ID·숫자·값의 대응이 유지되는지 확인한다. 실제 플래그 값이나 게임 판정은 변경하지 않는다. 기존 [플래그 검사 보고서](flag-localization-audit.md)는 과거 스냅샷이며, 수정 후 현재 게임에서 재검사한다.

### 4. 통합 검수와 공개 릴리스 정리

- 전환한 화면·AI 입력의 누락 검사를 합치고, 사용자 확인 결과를 버전별로 남긴다. 내부 키·로그·중국어 원문 자료와 실제 한국어 UI 누락을 구분한다.
- 저장/불러오기·이벤트 선택·조건/경로·수치 표시를 확인하고, UI 배치 유지 검사를 계속 통과시킨다.
- 공개할 버전의 README·변경 기록·설치 안내·ZIP·체크섬·소스 커밋을 맞춘다.
- 개발 브랜치, 기본 브랜치, 공개 릴리스의 버전 차이를 해소하고, 한국어판 업데이트 경로를 정리한다. 현재 내장 업데이트 안내와 원본 설치 프로그램은 원본 저장소 기준이다.

확인 기준: 설치용 ZIP과 해당 소스 커밋이 일치하고, 신규 설치·기존 한국어판 업데이트 안내가 명확하며, 확인된 한계를 릴리스에 명시한다.

## 계속 유지할 원칙

- 화면 비율·배치·고정 크기·글꼴·여백·디자인을 유지한다. 문구에 따른 기존 자동 줄바꿈·글자 폭 계산은 유지한다.
- 게임 연동·판정·이벤트 실행·저장 기능은 기존 구현을 유지하고, 표시 데이터와 문구 생성만 분리한다.
- ID·스크립트명·조건 분석용 원본·API 키 이름을 일괄 번역하지 않는다. 내부에 중국어가 있다는 이유만으로 기능용 데이터를 바꾸지 않는다.
- 버전은 실제 구현·검증·패키징이 끝난 뒤 기록한다. 위 작업 순서는 향후 버전이 이미 만들어졌다는 뜻이 아니다.
