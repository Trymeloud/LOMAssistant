# LOMAssistant 3.2.1-ko.3 — 표시 문구 조합·게임 대사 한국어 보완

원본 **v3.2.1**과 기존 한국어 개선을 누적 포함한 공개 사전 배포판입니다. 3.2.1-ko.1·ko.2를 따로 설치할 필요가 없습니다.

## 이전 공개판 3.0.9-ko.4에서 달라진 점

- 원본 3.1.0~3.2.1의 새 흐름도·진행 경로 배치, 유학 장소의 이벤트 미리보기·확률·미열람 표시를 반영했습니다. 메인 창 비율과 전체 스타일은 유지합니다.
- 스토리 점프의 확인·사전 퀵세이브·복귀 기능을 포함하며, 「채우지 못하는 것」의 주사위·전투 등 안내 5종을 한국어로 구성합니다. 점프는 중간 상태를 완전히 재현하지 못할 수 있으므로 별도로 백업한 저장에서 사용하세요.
- 선택지 이후 공통 변화의 표시 경계와 분석 캐시를 개선하고, 일부 환경의 AI JSON 호출 호환 수정·Gemini 추론 설정을 반영했습니다.
- 플래그 이름 1,069개, 문맥별 이벤트명 406개, 플래그 변화 팝업과 공식 한국어 대사 기반 AI 말투 개선을 유지합니다.

[3.2.1 통합 상세](https://github.com/Trymeloud/LOMAssistant/blob/korean-native-3.2.1/releases/v3.2.1-ko.1.md)

## 수정한 6개 영역

- **분기 선택창:** `接到「…」` 대신 `「…」(으)로 이어짐`으로 표시합니다. 타이틀·지도 복귀와 번호만 있는 분기도 한국어로 구성합니다.
- **결투 행동 예측:** 가로·세로 모두 행동명을 번역한 뒤 `적 예정 행동 찌르기`처럼 구성하며 대응 변경 안내도 한국어로 제공합니다.
- **비급 설명:** `✓ 3단계: 구력 +1`처럼 단계·보너스를 구성하고, 일부 비급의 주의문도 본문을 먼저 번역해 표시합니다.
- **설정·경고:** 행동력 무제한 주의문, 주의 접두사, 단축키 충돌 안내를 한국어로 구성합니다. 시작 때 저장한 충돌 원문은 화면 언어가 확정된 뒤 표시할 때 처리합니다.
- **퀵세이브 툴팁:** 사용자 메모 앞의 제목을 `메모:`로 표시합니다. 입력한 메모 내용은 수정하지 않습니다.
- **턴 넘기기:** 중요한 일이 있거나 시간이 늦어서 진행할 수 없을 때의 게임 대사 2곳을 한국어로 표시합니다.

분기 판정·주사위·보너스 수치·키 해제·턴 넘기기 실행 조건·저장 형식과 화면 배치는 유지합니다.

## 적용

1. 게임을 종료하고 기존 `BepInEx/plugins/LOMAssistant/LOMAssistant.dll`과 `event-names-ko.tsv`를 게임 폴더 밖에 백업합니다.
2. `LOMAssistant-3.2.1-ko.3-patch.zip` 안의 `BepInEx` 폴더를 게임 설치 폴더에 덮어씁니다. 기존 모드가 정상 작동한다면 원작을 다시 받을 필요가 없습니다. 기본 BepInEx 6·Newtonsoft.Json 환경은 별도로 필요합니다.
3. 한국어로 재실행하고 분기 선택창·결투 가로 표시·수치 탭 비급 설명·설정 경고·퀵세이브 메모 툴팁을 확인합니다. 확인을 위해 행동력 모드나 단축키 설정을 바꿀 필요는 없습니다.

공식 한국어 게임 `release_1.0.6001.0` 기준입니다. 빌드·자동 검사 **9,213건 통과**, 대상 **15개 구체 조합의 중국어 잔여 0건**을 확인했습니다. 실제 DLL에 각 표시 처리가 연결됐는지도 검사했습니다. 실제 게임 표시와 외부 AI 응답은 추가 확인이 필요합니다. F9 전체 설명의 한중 혼합 47건은 남아 있습니다.

ZIP에는 DLL·이벤트명 번역표·설치 안내·소스 커밋과 파일별 SHA-256 정보가 포함됩니다. `SHA256SUMS.txt`는 설치 ZIP의 체크섬입니다.
