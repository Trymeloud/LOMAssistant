# LOMAssistant 3.2.1-ko.2 — 점프 제한 안내 한국어 수정

원본 **v3.2.1** 기반 로컬 검증판입니다. ko.1 통합 내용을 누적 포함하며 GitHub에는 아직 공개하지 않았습니다.

## 수정 사항

스토리 점프 「채우지 못하는 것」에서 구간 제목 뒤의 주사위·전투 안내가 중국어로 남던 문제를 수정했습니다. 아래 5종 안내는 이제 기존 원문 문장 치환을 거치지 않고 한국어로 직접 생성합니다.

- 주사위: 실제로 굴리지 않고 선택한 경로의 변화를 채운다는 안내.
- 전투: 실제로 싸우지 않고 선택한 경로의 변화를 채운다는 안내.
- 임무 시작에서 목표 구간까지의 경로를 찾지 못한 경우.
- 현재 주요 임무와 목표 임무가 이어지지 않는 경우.
- 목표 구간이 현재보다 과거라 날짜를 되돌리는 경우.

점프 경로 선택·수치 보충·사전 퀵세이브·복귀 절차와 화면 배치는 유지합니다. 원작 3.2.1의 흐름도·진행 경로 개편, 유학 이벤트 안내, AI 연결 수정과 기존 한국어 플래그·이벤트명·AI 말투 개선도 포함합니다.

## 적용

1. 게임을 종료하고 기존 `BepInEx/plugins/LOMAssistant/LOMAssistant.dll`과 `event-names-ko.tsv`를 게임 폴더 밖에 백업합니다.
2. `LOMAssistant-3.2.1-ko.2-patch.zip` 안의 `BepInEx` 폴더를 게임 설치 폴더에 덮어씁니다. 기존 모드가 정상 작동한다면 원작 모드를 다시 받을 필요가 없습니다. 기본 BepInEx 6·Newtonsoft.Json 환경은 별도로 필요합니다.
3. 한국어로 재실행하고 저장을 불러온 뒤 점프 확인 화면을 다시 엽니다. 「채우지 못하는 것」의 주사위·전투 및 기타 안내가 한국어인지 확인합니다. 안내 문구 확인만으로 점프를 실행할 필요는 없습니다.

공식 한국어 게임 `release_1.0.6001.0` 기준입니다. 빌드·자동 검사 **9,119건 통과**. DLL의 안내 생성 경로와 긴 제목·말줄임표 조합을 검사했으며 실제 게임에서의 수정 결과는 후속 확인이 필요합니다. F9 전체 설명의 한중 혼합 47건과 AI 실사용 검증 범위는 이전과 같습니다.

ZIP에는 DLL·이벤트명 번역표·설치 안내·소스 커밋 및 SHA-256 정보가 포함됩니다. `SHA256SUMS.txt`는 설치 ZIP의 체크섬입니다.
