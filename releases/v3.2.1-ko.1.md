# LOMAssistant 3.2.1-ko.1 — 한국어 개선 통합 검증판

원본 **v3.2.1**과 기존 **3.0.9-ko.4** 한국어 개선을 통합한 로컬 검증판입니다. GitHub에 아직 공개하지 않았습니다. 공식 한국어 게임 `release_1.0.6001.0` 기준입니다.

## 원본에서 가져온 변경

- 건물·활동·외출 및 공동·청성 유학 장소의 선택지별 이벤트 미리보기, 확률·미열람 표시와 미열람 판정 보완.
- 흐름도 안에 선택지별 행과 연결선을 표시하고, 진행 경로의 본편·분기·합류 및 조건 배치를 개편. 메인 창 비율과 전체 스타일은 유지하며, 그래프 배치는 사용자 선택에 따라 원본 3.2.1을 반영했습니다.
- 스토리 점프: 중간 선택·변화를 확인하고 목적 구간으로 이동하며 점프 전 퀵세이브를 남깁니다. 원본의 확인·저장·복귀 절차를 유지했습니다.
- 선택지 묶음 이후의 공통 변화가 마지막 선택지만의 변화로 표시되던 문제 수정, 분석 캐시를 통한 다음 실행의 로딩 단축.
- 일부 환경의 AI 무반응 원인이었던 JSON 호출 호환 수정, Google 직접 연결의 Gemini 3 일반 `low`/심층 `medium` 추론 강도, 최신 제공업체 프리셋.
- 최근 질문의 언어를 따르는 답변 지시, 인물이 조활에게 느끼는 호감도 변경과 확인 카드 안내 보완.

## 한국어 개선 유지·연결

- 1,069개 플래그 ID 이름, 기존 스토리·조건·결과 직접 생성, 플래그 변화 팝업과 공식 한국어 대사 기반 인물 호칭·말투를 유지했습니다.
- 기존 406개 ID·원문 조합의 이벤트명을 우선합니다. 원본의 고정 이벤트명 110개와 공통 결과명 규칙을 보조로 사용하며, 같은 ID가 다른 지역에서 쓰여도 이름을 빌려 쓰지 않습니다.
- 새 경로의 짧은 조건은 한국어 조건에서 만들고, 점프·흐름도 효과는 한국어로 표시합니다. 경로 합산과 점프 명령은 원본 자료를 사용합니다.
- 캐시는 동작 객체와 번역된 설명 대신 동작의 원시 입력을 저장합니다. 캐시 로드는 백그라운드에서, 표시용 동작 복원은 게임 메인 스레드에서 수행합니다.

## 설치·실행 확인

기존 한국어판과 BepInEx 6·Newtonsoft.Json 환경이 정상 작동한다면 원작 3.2.1을 다시 설치할 필요 없이 이 패치 ZIP을 덮어쓸 수 있습니다. 기본 로더와 Newtonsoft.Json은 ZIP에 포함하지 않습니다.

1. 게임을 종료하고 기존 `BepInEx/plugins/LOMAssistant/LOMAssistant.dll`과 `event-names-ko.tsv`를 게임 폴더 밖에 백업합니다.
2. `LOMAssistant-3.2.1-ko.1-patch.zip` 안의 `BepInEx` 폴더를 게임 설치 폴더에 덮어씁니다. DLL을 다른 이름으로 추가해 두 버전을 함께 넣지 마세요.
3. 한국어 표시로 실행하고 저장을 불러온 뒤 자료 로딩이 완료될 때까지 기다립니다.
4. 현재 상황·흐름도·진행 경로에서 조건·읽음·선택 결과가 한국어인지 확인합니다. 건물 활동 및 공동·청성 장소의 이벤트 이름·확률·안 읽음 표시도 확인합니다.
5. 한 번 종료·재실행해 캐시를 읽은 뒤에도 한국어 효과와 조건이 같은지 확인합니다.
6. AI는 새 대화에서 확인합니다. 저장된 모델명은 자동 변경되지 않으며, 제공업체를 다시 선택하면 원본의 새 기본 모델이 적용됩니다. 외부 AI 사용에는 제공업체의 기존 요금이 적용됩니다.
7. 스토리 점프를 확인한다면 별도로 백업한 저장에서 변경 확인 화면·점프 전 퀵세이브·점프 후 복귀를 확인합니다. 원본 안내처럼 일반 플레이에는 권장하지 않으며 중간 상태를 완전히 채우지 못할 수 있습니다.

## 검증·남은 범위

빌드·자동 검사 **9,095건 통과**. [통합 보고서](../reports/upstream-3.2.1-korean-review.md)에 소스 대조와 검사 범위를 기록했습니다. 실제 게임의 점프·캐시 로딩·외부 AI 생성은 아직 확인하지 않았습니다. 설정·저장 화면의 후속 전환과 F9 전체 설명의 한중 혼합 47건은 남아 있습니다.

설치 ZIP은 DLL·이벤트명 번역표·설치 안내·소스 커밋과 파일별 SHA-256 정보를 포함합니다. GitHub 자동 `Source code` 압축 파일은 설치용이 아닙니다.
