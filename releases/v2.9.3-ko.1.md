# LOMAssistant 한국어 개선판 2.9.3-ko.1

원본 LOMAssistant 2.9.3을 기반으로 한 비공식 한국어 개선판의 첫 사전 배포입니다. 활협전 공식 한국어를 기준으로 작업했습니다.

## 다운로드 및 설치

설치용 파일은 **`LOMAssistant-2.9.3-ko.1-patch.zip`**입니다. 아래의 `Source code` 파일은 개발용 소스입니다.

이 ZIP은 기존 **LOMAssistant 2.9.3 / BepInEx 6** 설치에 적용하는 패치입니다. 처음 설치한다면 [원본 2.9.3 릴리스](https://github.com/kevinnie2003/LOMAssistant/releases/tag/v2.9.3)를 먼저 설치하세요. BepInEx와 Newtonsoft.Json은 이 패치에 포함하지 않습니다.

1. 게임을 종료합니다.
2. 기존 `BepInEx/plugins/LOMAssistant/LOMAssistant.dll`과 `event-names-ko.tsv`가 있다면 게임 폴더 밖에 백업합니다.
3. ZIP 안의 `BepInEx` 폴더를 게임 설치 폴더에 덮어씁니다.
4. `LOMAssistant.dll`과 `event-names-ko.tsv`가 같은 폴더에 있는지 확인하고, 한국어로 게임을 실행합니다.

기존 DLL을 다른 이름으로 남겨 두면 중복 로드될 수 있으므로 교체해서 사용하세요. 번역표 수정은 게임 재실행 후 반영됩니다. 되돌리려면 백업 파일을 복구합니다.

원본 설치 프로그램과 모드의 내장 업데이트 안내는 원본 프로젝트를 기준으로 합니다. 원본 업데이트를 적용하면 개선판이 교체될 수 있으므로, 개선판의 새 버전은 [이 포크의 릴리스](https://github.com/Trymeloud/LOMAssistant/releases)에서 확인하세요.

## 변경 사항

- 플래그 이름 841개와 조건 이름 212개의 한국어 번역 보완.
- 공식 한국어를 참고한 인물명·능력치·장소명 정리.
- 스토리 제목, 현재 상황, 분기 목적지 등의 문장 조합 및 잘림 표시 개선.
- 랜덤 이벤트 표시 이름 397개를 `event-names-ko.tsv`로 제공.
- 실제 게임 데이터를 읽어 플래그 표시 누락을 검사하는 도구와 검사 보고서 추가.

게임 판정·확률·플래그 값·저장 처리 코드의 변경은 이번 소스 비교에서 발견하지 못했습니다. 이번 배포 준비에서는 버전 식별 정보와 배포 문서·번역표·패키징 도구를 추가했습니다.

## 검증 결과와 알려진 문제

- 소스 빌드 성공, 기존 번역 검사 2,961건 통과.
- 실제 플래그 표시 조합 5,304건 실패 0건, 수집된 조건 5,054건에서 중국어 잔여 0건.
- **F9 플래그 전체 설명에는 한중 혼합 표기 47건이 남아 있습니다.** [상세 보고서](https://github.com/Trymeloud/LOMAssistant/blob/v2.9.3-ko.1/reports/flag-localization-audit.md)
- 일부 스토리 제목과 수집 현황에도 미번역이 남을 수 있습니다.
- 번역용 이벤트 목록 내보내기가 실패하면 같은 게임 데이터에서는 재시도하지 않는 문제가 있습니다. 제공된 이벤트명 번역표를 읽는 기능과는 별개입니다.
- 검사에 사용한 게임 버전: `release_1.0.6000.5`. 자동 검사는 번역 적용·누락 검사이며, 전체 번역의 의미 검수나 모든 게임 상황의 실플레이 검증을 대신하지 않습니다.

ZIP에는 빌드한 DLL, 이벤트명 번역표, 설치 안내와 파일 해시·소스 커밋을 기록한 `release-info.json`이 들어 있습니다. 함께 제공하는 `SHA256SUMS.txt`로 ZIP의 SHA-256을 확인할 수 있습니다.
