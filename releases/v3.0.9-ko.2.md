# LOMAssistant 3.0.9-ko.2 — 스토리 화면 한국어 전환

원본 v3.0.9와 공식 한국어 게임 `release_1.0.6001.0` 기준입니다. 사용자가 작동을 확인한 ko.1에 이어, 진행 경로·흐름도·수집 현황의 표시 문구를 전환한 검증판입니다. GitHub 공개 릴리스는 아직 만들지 않았습니다.

## 변경 사항

- 진행 경로의 날짜, 이번 회차 방문 여부, 대사 읽은 비율, 결말 개수, 인연 단계·호감도와 검색 안내를 한국어 문구 키로 생성합니다.
- 흐름도의 선택지·주사위·전투 태그, 조건, 결말·사망·다른 임무로의 연결, 읽음·저장 표시와 상세 안내를 한국어로 생성합니다.
- 수집 현황의 분류·필터·정렬, 달성·미달성·읽음 상태, 발생 경로와 크레딧 안내를 전환합니다. 모든 회차의 달성 기록과 이번 회차의 방문 기록을 구분합니다.
- 날짜는 연·월·순과 기간 정보로 표시합니다. 임무 판정과 정렬에 사용하는 기존 날짜·조건 데이터는 유지합니다.
- 긴 임무 이름은 완전한 이름을 조회한 뒤 표시하며, `이름 - 한정 조건`처럼 합쳐진 이름도 전체 번역을 우선합니다.
- 언어를 바꾸면 그래프·문구 캐시를 갱신해 이전 언어가 남지 않게 합니다.
- 화면 비율·배치·고정 크기·여백·글꼴·색상 설정은 유지합니다. 승인된 ko.1 소스와 좌표·스타일·배율·폭/높이·여백 표현식을 비교하는 검사를 추가했습니다. 글 내용에 따른 기존 자동 줄바꿈·글자 폭 계산은 유지합니다.

## 적용

1. 게임을 완전히 종료합니다.
2. 기존 `BepInEx/plugins/LOMAssistant/LOMAssistant.dll`과 `event-names-ko.tsv`를 게임 폴더 밖에 백업합니다.
3. ZIP의 `BepInEx` 폴더를 게임 설치 폴더에 덮어씁니다. DLL과 이벤트명 표를 함께 교체하고, DLL 두 버전을 다른 이름으로 함께 넣지 마세요.
4. 표시 언어를 한국어로 설정하고 재실행합니다.

ko.1의 BepInEx 6·Newtonsoft.Json 환경을 그대로 사용합니다. 빌드·패키징 과정에서 게임 설치 폴더·설정·저장은 수정하지 않았습니다.

## 이번에 확인할 항목

1. **진행 경로:** 연·월·상순/중순/하순, 「이번 회차에 지나옴」과 「대사 ○% 읽음」이 구분되는지, 인연 단계·호감도와 임무 상세가 맞는지 확인합니다.
2. **스토리 흐름도:** 상자·연결선의 문구, 조건의 비교 기호·수치, 전투 패배로 인한 사망 경로와 결말 이름을 확인합니다. 상자를 눌러 상세와 읽음 표시도 확인합니다.
3. **수집 현황:** 스토리·결말·사망·업적·CG 분류와 달성 필터를 바꿔 보고, 기존 달성 기록·개수와 발생 경로가 유지되는지 확인합니다.
4. 표시 언어를 잠시 바꿨다가 한국어로 돌아왔을 때 이전 문구가 남지 않는지 확인합니다.

## 검증과 남은 범위

빌드 및 자동 검사 7,702건 통과. 설치된 게임의 임무 메타데이터 511개(임무 그룹 211개·단계 300개)의 이름·설명 첫 줄을 검사했으며 중국어 잔여는 0건입니다. 화면의 모든 동적 조합을 실제 플레이로 확인했다는 의미는 아닙니다.

ko.2는 아직 게임에 자동 적용하지 않았으며 실제 플레이 확인이 필요합니다. 설정·저장 화면·AI 내부 안내와 F9 전체 설명의 한중 혼합 47건은 후속 전환 대상으로 남아 있습니다. ko.1의 현재 상황 추적·조건/결과 생성·AI 말투·이벤트명 문맥 수정은 포함합니다.
