# LOMAssistant 3.0.9-ko.1 — 한국어 구조 전환 1단계 검증판

원본 v3.0.9 (`f0313b7ced47a798bf90884b2c7c51cfc115b163`)과 공식 한국어 게임 `release_1.0.6001.0` 기준입니다. GitHub 공개 릴리스는 아직 만들지 않았습니다.

## 변경 사항

- 원본 3.0.7~3.0.9의 수치 프리셋, 저장 호환 확인, 글자 잘림·색상 개선과 버그 수정을 반영했습니다.
- 현재 상황 탭의 제목·버튼·안내를 고유 키로 조회하는 한국어 문구로 전환했습니다. 조건과 선택 결과는 비교 연산·값·동작 종류를 받아 한국어로 조립합니다.
- 플래그 이름 1,069개를 ID로 조회합니다. 기존 검수 번역을 사용하며, 설명이 없는 플래그는 ID를 유지합니다. 표는 DLL에 내장됩니다.
- 공동·청성 유학 장소 13개를 ID로 표시합니다. 공식 한국어 이동 메뉴의 장소명을 참고했습니다.
- 「선택지 정보·판정 기록」을 꺼도 현재 상황 탭의 스토리 추적은 작동하도록 분리했습니다. 게임 선택지의 결과 표시나 회상 판정 기록을 강제로 켜지는 않습니다.
- 같은 스크립트 안에서 선택지·주사위 목록이 바뀌면 현재 상황 탭을 갱신하고, 화면에 나온 순서대로 표시합니다. 표시할 내용이 없는 장면과 읽기 오류를 구분합니다.
- 역검색·경로 분석용 원본 데이터는 유지하고, 화면용 한국어 결과를 별도로 만듭니다. 실제 선택·플래그 변경·난수 추첨은 이 한국어 코드가 실행하지 않습니다.
- 기존 ko.5까지의 이벤트명 문맥 수정, 공식 한국어 대사 기반 AI 인물 말투를 유지합니다.

## 적용

1. 게임을 완전히 종료합니다.
2. 기존 `BepInEx/plugins/LOMAssistant/LOMAssistant.dll`과 `event-names-ko.tsv`를 게임 폴더 밖에 백업합니다.
3. ZIP의 `BepInEx` 폴더를 게임 설치 폴더에 덮어씁니다. DLL과 이벤트명 표를 함께 교체합니다. 원본 DLL과 새 DLL을 다른 이름으로 함께 넣지 마세요.
4. 게임과 모드의 표시 언어를 한국어로 설정합니다.

BepInEx 6과 `Newtonsoft.Json.dll`이 필요합니다. 기존 3.0.6 한국어판에서 사용하던 해당 로더·라이브러리 환경에도 적용할 수 있습니다. 게임 설치 폴더에는 자동 적용하지 않았습니다. 되돌리려면 게임을 종료한 뒤 백업한 두 파일을 복구합니다.

## 실제 게임에서 확인할 항목

1. 「선택지 정보·판정 기록」을 끄고 게임을 재시작한 상태에서 선택지·주사위 화면의 현재 상황 탭에 결과가 나오는지 확인합니다. 「선택지 결과」 표시 방식은 원하는 대로 유지합니다.
2. 공동 유학 중 무색광장·비천전 등에서 조건·이벤트명·결과를 확인합니다. 유학 지도 메뉴 자체에는 아직 해당 장소의 이벤트 풀이 없으므로, 모든 장소 이벤트를 미리 한꺼번에 나열하지 않습니다.
3. 같은 장면에서 다음 선택이나 주사위로 넘어갔을 때 「지금 선택할 수 있는 항목」이 바뀌는지 확인합니다.
4. 호감도·수치 변화와 플래그 ID가 맞는지, 「수치」의 역검색과 흐름도 이동이 유지되는지 확인합니다.
5. 기존 저장을 불러오고, 원본 3.0.9의 수치 프리셋·저장 화면도 확인합니다.

## 검증과 남은 범위

빌드 및 자동 검사 7,101건 통과. 생성 DLL의 추적 패치 분리·중복 없음·분석용 원본 유지·내장 표를 검사했습니다. 플래그 표시 조합 5,304건 실패 0건, 기존 게임 조건 캐시 5,060건의 번역 누락 0건입니다.

실제 게임에서 새 DLL을 실행하거나 유료 AI API에 요청한 것은 아닙니다. 모든 화면의 완전한 구조 전환도 아닙니다. 진행 경로·수집 현황·설정·AI 안내에는 기존 번역 처리가 남아 있으며, F9 플래그 전체 설명에는 기존 한중 혼합 47건이 남아 있습니다. AI가 생성하는 답변의 언어는 별도 검증 대상입니다.

후속 확인(2026-10-29): 사용자가 ko.1 적용 후 안내한 점검에 대해 「잘 됨」으로 작동을 확인했습니다. 모든 스토리·저장·AI 기능을 개별 검증했다는 의미는 아닙니다. 화면 비율·배치·크기·디자인을 유지하는 조건으로 다음 단계를 진행합니다.
