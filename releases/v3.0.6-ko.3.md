# LOMAssistant 한국어 개선판 3.0.6-ko.3

원본 LOMAssistant 3.0.6 / 게임 1.0.6001 기준의 AI 답변 언어 보완판입니다. 3.0.6-ko.2의 수정 사항을 포함합니다.

## 수정 사항

- 한국어 설정에서도 AI 인물 설정의 중국어 호칭·자칭·어미를 그대로 섞어 쓰던 문제에 대응해, 한국어 응답 규칙과 인물명 표기를 추가했습니다. 중국어 자료와 과거 혼합 답변을 답변의 언어·말투로 따라 쓰지 않도록 안내합니다.
- 엽운상의 `哥哥`, `赵哥哥`, `裳儿`, `的说`를 자연스러운 한국어 호칭과 말투로 표현하도록 보완했습니다.
- 중국어 `[表情: …]`와 영어 `[mood: …]` 외에 한국어 `[표정: …]`도 표정 정보로 인식해 본문에서 제거합니다. 스트리밍 중에도 같은 처리를 적용합니다.
- 새 규칙은 한국어 설정에서만 적용합니다. 도구 실행·게임 수치 변경·저장 동작은 기존과 같습니다.

## 설치 및 확인

1. 게임을 종료하고 기존 `LOMAssistant.dll`을 게임 폴더 밖에 백업합니다.
2. 게임 1.0.6001과 원본 LOMAssistant 3.0.6 또는 3.0.6-ko.1/ko.2가 설치된 상태에서, `LOMAssistant-3.0.6-ko.3-patch.zip`의 `BepInEx` 폴더를 게임 폴더에 덮어씁니다.
3. 모드 표시 언어를 한국어로 설정하고 AI 탭에서 **새 대화**를 시작해 확인합니다. 기존 대화 기록은 자동으로 번역하거나 지우지 않습니다.

새 대화에서 엽운상에게 한국어로 질문하고, 호칭·자칭·말끝에 중국어가 섞이는지와 `[표정: …]` 태그가 본문에 남는지 확인해 주세요.

## 검증 범위

- 번역·응답 규칙·표정 태그 검사 **3,117건 통과**. 한국어·중국어·영어 표정 태그, 잘못된 표정의 기본값 처리, 다른 언어 프롬프트 보존을 검사했습니다.
- 내장 조건의 중국어 잔여 0건, 플래그 표시 조합 5,304건 실패 0건, 수집 조건 5,060건의 중국어 잔여 0건입니다.
- 실제 외부 AI 서비스에 질문을 보내는 검증은 수행하지 않았습니다. 응답 규칙이 모델의 출력을 완전히 보장하지는 않습니다. 추가 번역 API 호출이나 자동 재질문은 하지 않습니다.
- 기존 한중 혼합 답변은 과거 대화에 남아 있습니다. F9 전체 설명의 기존 한중 혼합 47건 등 알려진 번역 누락도 남아 있습니다.

설치 ZIP에는 DLL, 이벤트명 번역표, 이 안내와 `release-info.json`이 포함됩니다. BepInEx·Newtonsoft.Json은 포함하지 않습니다.
