# LOMAssistant 3.0.9-ko.4 — 플래그 변화 팝업 한국어 연결

원본 **3.0.9 기반** 공개 사전 배포판입니다. ko.3까지의 한국어 개선을 누적 포함하며, 이번에는 플래그 변화 팝업의 번역 누락을 수정했습니다. **원본 3.1.0 변경 사항은 포함하지 않습니다.**

## 변경 사항

- 플래그 변화 알림이 모드 창의 번역 처리를 거치지 않고 게임 팝업에 중국어 개발 메모를 바로 전달하던 문제를 수정했습니다.
- 한국어에서는 기존 플래그 ID별 한국어 이름표를 사용해 `【플래그】이름  이전값 → 새값`을 직접 구성합니다. 미등록 플래그는 중국어 개발 메모 대신 ID를 표시합니다.
- 다른 표시 언어에서도 게임 팝업에 번역 처리를 명시적으로 적용합니다.
- 변경 감지·수치 처리·임시 플래그 제외·팝업 위치·유지 시간은 기존대로입니다.

기존 스토리 화면과 AI 채팅 개선은 [ko.3 변경 사항](https://github.com/Trymeloud/LOMAssistant/releases/tag/v3.0.9-ko.3)에 정리되어 있습니다.

## 설치·업데이트

기존 한국어판이 정상 작동한다면 **원작자의 3.0.9를 다시 받을 필요가 없습니다.** 이번 ZIP만 덮어쓰면 됩니다.

1. 게임을 완전히 종료합니다. 기존 `BepInEx/plugins/LOMAssistant/LOMAssistant.dll`과 `event-names-ko.tsv`는 게임 폴더 밖에 백업합니다.
2. `LOMAssistant-3.0.9-ko.4-patch.zip`을 풀고, 안의 `BepInEx` 폴더를 게임 설치 폴더에 덮어씁니다. DLL을 다른 이름으로 추가해 두 버전을 함께 넣지 마세요.
3. 게임과 모드 표시 언어를 한국어로 설정하고 재실행합니다.
4. 모드 설정에서 플래그 변화 알림을 켜고, 스토리를 진행해 팝업의 이름과 이전값 → 새값 표시를 확인합니다.

기존 설정·저장 파일은 교체 대상이 아닙니다. 처음 설치한다면 BepInEx 6·Newtonsoft.Json 환경이 별도로 필요합니다. 설치용 ZIP에는 이 기본 실행 환경을 포함하지 않습니다. 공식 한국어 게임 `release_1.0.6001.0` 기준입니다.

## 검증·남은 범위

- 빌드·자동 검사 **8,890건 통과**. 팝업 문구의 값 순서·음수·감소·미등록 ID 처리와 빌드된 DLL의 한국어 이름 조회 및 게임 알림 번역 경로를 검사했습니다.
- 기존 플래그 표시 조합 5,304건 실패 0건, 실제 캐시 조건 5,060건의 중국어 잔여 0건입니다. 화면 배치 유지와 기존 스토리·AI 오프라인 검사도 통과했습니다.
- 이번 수정의 실제 게임 팝업 표시는 아직 확인하지 않았습니다. F9 전체 설명의 한중 혼합 47건과 설정·저장 화면의 후속 전환은 남아 있습니다. AI 실사용 검증 범위도 ko.3과 같습니다.
