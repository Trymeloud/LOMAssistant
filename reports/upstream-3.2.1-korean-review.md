# 원본 3.2.1 한국어 보완 대조 및 통합

검토일: 2026-10-30. 비교 대상: 원본 `v3.0.9` → `v3.2.1`, 기존 한국어판 `v3.0.9-ko.4`. 통합 브랜치: `korean-native-3.2.1`, 버전: `3.2.1-ko.1`.

## 원본 한국어 보완의 실제 범위

- `UiEventNames.Table`에 고정 원문 이벤트명 **110개**가 있습니다. 기존 `localization/event-names-ko.tsv`와 원문 기준으로 대조하면 **110개 모두 번역이 같습니다**. 원본 주석은 플레이어가 issue #27에 제공한 이름표라고 설명합니다. 이 대조는 모든 대사·플래그·문맥의 의미 검수가 완료됐다는 뜻은 아닙니다.
- 원본은 `P_大失敗_001`, `P_成功_001` 등 **7종 결과 단어**를 규칙으로 번역하며 접두사·번호는 보존합니다. 고정 표는 한국어, 결과 단어 규칙은 한국어·일본어·영어를 지원합니다.
- 기존 개선판에는 **406개 ID·원문 조합, 397개 ID, 136개 원문 이름**이 있습니다. 원작 고정 표와 겹치지 않는 원문 26개는 모두 `P_*` 형식입니다. 따라서 고정 이름 개수만으로 개선판의 의미 범위가 더 넓다고 해석하면 안 됩니다. 기존 표의 장점은 ID 재사용 문맥을 구분하고, 결과 번호를 한국어 이름으로 표시하며 사용자가 수정할 수 있다는 점입니다.
- 새 스토리 점프 안내와 설정 이름 단축 등 일반 UI 번역도 추가됐습니다. 플래그 ID별 한국어 리소스, 공식 한국어 대사 기반 AI 말투, 기존 스토리 직접 생성 구조는 원작이 대체하지 않으므로 유지했습니다.

## 통합 시 보완한 경계

1. 이벤트명은 기존 ID·원문 조합을 먼저 조회하고, 실패하면 원본 표와 결과명 규칙으로 표시합니다. 원본 `GetEventName(..., false)` 경로는 원문 분석용으로 유지합니다.
2. 원본 새 진행 경로는 조건 문장을 중국어 구분자로 분석합니다. 한국어판은 한국어 조건에서 시간·행동력을 제외하고 플래그 번호별 설명을 찾아, 번역된 이름이 잘리기 전에 짧은 조건을 만듭니다.
3. 새 흐름도 내부에 남는 선택지의 효과 및 점프 확인 효과는 한국어 표시 자료를 사용합니다. 실제 점프 명령과 AI 경로 합산은 원본 자료를 유지합니다.
4. 원본 캐시는 파싱된 `StoryScript`를 백그라운드에서 JSON으로 읽고 씁니다. 한국어판의 표시용 `Action`을 그대로 캐시하면 번역·게임 조회와 객체 복원이 백그라운드로 들어갈 수 있어, 타입·입력·경로만 저장하고 `StoryScripts.Remember`에서 복원합니다. JSON 컬렉션 재사용으로 복원 목록이 소실되지 않도록 교체 역직렬화를 지정했습니다.
5. AI의 원본 JSON 호환·Gemini 추론 설정은 그대로 적용합니다. 한국어 프롬프트에도 최신 메시지의 언어 우선과 인물 호감도 대상을 안내합니다. 기존 목소리·스포일러·대사 읽음 제한·사용자 확인 후 수치 변경은 유지합니다.

## 검사

- 실제 3.2.1 요청 생성 코드를 오프라인 실행해 Google Gemini 일반/심층 추론 강도, 다른 주소 비간섭, 도구 15개 유지와 Sol 도구 설정을 검사합니다. API를 호출하지 않습니다.
- 실제 캐시 코드로 메모리·디스크 JSON 왕복과 배경 스레드 로딩, 메인 스레드 복원, 명령·선택 경로 보존, 버전 변경·손상 캐시의 재파싱을 검사합니다.
- 실제 이벤트명 조회 코드로 원작 110개 이름·7종 결과명·기존 문맥 우선·ID 재사용과 다른 언어 비간섭을 검사합니다.
- 실제 선택지 블록 추출 코드로 마지막 선택지에 메뉴 이후 공통 효과가 붙지 않는지 검사합니다.
- 원작과 토큰을 비교해 AI 전송 및 스토리 점프의 실행·게임 변경·사전 저장/복귀 조건을 유지했는지 확인합니다. 파서는 원본과 비교하되 기존 표시/분석 분리만 정규화합니다.
- 메인 창·AI 화면은 승인된 ko.1, 흐름도·진행 경로·점프 화면은 사용자가 선택한 원본 v3.2.1을 기준으로 배치·스타일을 비교합니다.

빌드·자동 검사 **9,095건 통과**. 플래그 표시 조합 5,304건 실패 0건, 실제 캐시 조건 5,060건 중국어 잔여 0건, 게임 임무 제목 후보 511개 중국어 잔여 0건입니다. 정적 문자열 후보에는 내부 키·로그·비한국어 분기도 포함되므로 해당 후보 수를 실제 미번역 화면 수로 해석하지 않습니다.

실제 게임·외부 모델 답변·점프 실행은 검증하지 않았습니다. F9 전체 설명 혼합 표기 47건은 이번 범위에서 수정하지 않았습니다.
