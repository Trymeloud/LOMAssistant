# 한국어 중심 구조 전환 — 3.0.9-ko.1

작업일: 2026-10-29. 브랜치: `korean-native-3.0.9`.

## 기준과 목적

원본 v3.0.9 태그 `f0313b7ced47a798bf90884b2c7c51cfc115b163`을 ko.5에 병합했다. 원본 3.0.6 대비 변경은 44개 파일, 추가 1,256행·삭제 100행이다. 게임은 공식 한국어 `release_1.0.6001.0`이다.

이전 구조는 중국어로 완성한 문장을 IMGUI 표시 직전에 번역했다. 새 문장·태그·동적 이름 조합·번역 전 축약을 모두 문자열 매칭으로 처리해야 했다. 이번에는 게임 데이터와 표시 문장을 분리하는 첫 단계를 구현했다. 기존 화면 배치는 유지한다.

## 이번에 전환한 부분

| 역할 | 구현 |
|---|---|
| 한국어 문장 키 | `KoreanMessage`와 `KoreanText`: 현재 상황·조건·효과·이벤트 설명의 문구. 중국어 문장을 입력받지 않고 키와 값으로 생성 |
| 이름 해석 | `KoreanLabels`: 플래그는 ID 표로 조회. 일반 변수명은 기존 검수 표를 재사용. 등록되지 않은 이름의 중국어가 남으면 기존 로그에 한 번 기록 |
| 플래그 ID 표 | `localization/flag-names-ko.tsv`: 기존 게임 플래그 감사의 검수 번역을 재사용한 1,069개 ID. 설명 없는 185개는 ID 유지. DLL 내장 |
| Lua 효과 | `KoreanActionCall`로 호출 종류·대상·정수 값을 읽고 `NativeKorean`에서 공식 게임 명칭을 조회한 뒤 한국어 생성. Lua 실행 없음 |
| 현재 상황 | 제목·버튼·빈 장면·오류·임무 준비 상태를 키로 표시. 선택지 목록 변경과 표시 언어 변경 시 갱신 |
| 스토리 관찰 | `StoryContextPatch`의 관찰용 패치 4개를 안내 설정과 독립적으로 설치. 기존 OptionInfoPatch의 중복 등록 제거 |
| 분석용 데이터 | `Action.CanonicalDescription`과 기존 `StoryScript.Effects` 유지. 별도 `DisplayEffects`가 한국어 표시를 담당 |
| 유학 장소 | 공동·청성 13개 장소 ID. 공식 `O_Section_01_Free_Start_02_*`, `O_Section_02_Free_Start_02_*` 메뉴의 비천전·탈백삼림·철권항·현공동·무색광장·상풍관 등의 표기 확인. 휴식 항목은 「휴식」으로 표시 |

조건을 읽을 때 `GetResult`와 `Check`의 호출 수·순서는 기존과 유지한다. 조건 템플릿 저장(`ConditionBook`)과 역검색의 입력은 기존 형식을 유지한다. 흐름도의 축약은 한국어 조건의 현재 값만 제거하며 연산자·조건 값·ID를 보존한다.

선택지의 `--index` 표기가 없는 특수 메뉴나 주사위도 게임이 실제 제시한 키를 현재 상황에 포함한다. 해당 키와 연결된 스크립트 효과만 사용하며, 뒤에 다른 분기가 있는 효과는 확정 효과와 나누어 표시한다. 선택지나 이벤트를 실행하는 코드는 바꾸지 않았다.

## 자동 검증

- 원본 병합 직후: 빌드 성공, 기존 번역 검사 3,619건 통과.
- 한국어 구조 전환 후: 빌드 성공, 자동 검사 7,101건 통과. 새 문구 키의 누락·중국어·매개변수, 6종 비교 연산·플래그 ID·양수/음수/대입·조건별 효과 구분, Lua 호출의 대상·음수·미평가 표현, 1,069개 ID와 기존 검수 번역의 일치를 검사했다.
- `BuiltModChecks`는 실제 생성 DLL의 Harmony 대상 4개, 관찰 함수의 반환값·참조 매개변수 없음, 중복 등록 없음, 안내 설정 분기 이전 설치, 분석 시 원본 설명 사용, 내장 ID 표, 한국어 어댑터에 수치 변경·난수 호출 없음 등을 검사했다. 이는 게임을 실행한 테스트를 대체하지 않는다.
- 기존 플래그 표시 조합 5,304건: 실패 0건. 기존 게임 조건 캐시 5,060건: 중국어 잔여 0건. 이 두 결과는 기존 번역 처리의 회귀 검사이며, 새 런타임 화면을 직접 관찰한 결과가 아니다.
- UI 소스의 중국어 후보 168건에는 로그·내부 키·기존 방식의 문구가 섞여 있다. 실제 미번역 화면 수나 남은 작업량으로 간주하지 않는다.
- 기존 빌드 경고 2건(`ConditionBook.Book.Combats`, `_aiFocusInput`)은 유지된다.

명령:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build-ko.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tools/ko-check/run.ps1 -GameFlags bin/ko-check/game-flags-3.0.6.json -LiveConditions '게임 폴더/BepInEx/plugins/LOMAssistant/StoryReview/conditions.json' -ModAssembly bin/LOMAssistant.dll
```

## 남은 단계

- 진행 경로·수집 현황·설정·저장 화면·AI 안내의 나머지 문구를 고유 키로 전환한다. 이번 단계에서 전체 UI를 다시 작성한 것은 아니다.
- AI 배경 설정·도구 설명·조회 결과의 중국어 중심 구성은 별도 전환 대상이다. ko.5의 한국어 응답·인물 말투 규칙은 유지했다.
- F9 플래그 전체 설명의 한중 혼합 47건은 남아 있다. ID별 이름 표 추가가 전체 개발자 주석 번역 완료를 의미하지 않는다.
- 조건 캐시의 저장 형식은 후속 버전에서 구조화할 수 있지만, 기존 분석 기능과 공유하는 현재 단계에서는 원본을 유지한다.
- 게임 설치·저장·설정과 GitHub 공개 릴리스는 자동 변경하지 않았다. 새 DLL을 적용한 실제 플레이 확인이 필요하다.
