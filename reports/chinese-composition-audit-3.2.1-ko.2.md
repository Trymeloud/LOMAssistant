# 3.2.1-ko.2 중국어 문장 조립 점검

검사일: 2026-10-30. 실행 코드 기준: `7728521` (`3.2.1-ko.2`). 점검은 소스 추적과 실제 `UiText.Translate` 실행으로 수행했으며 게임 화면을 자동 조작하거나 외부 AI를 호출하지 않았습니다.

**중국어 문장을 조립하는 표시 경로가 아직 남아 있습니다.** 정상 번역되는 기존 처리도 있지만, 일부 조합에서는 한국어 문구와 중국어가 섞입니다. 이번 작업은 검사 도구·보고서 추가이며 실행 DLL과 설치 ZIP은 ko.2 그대로입니다.

## 범위와 수치의 의미

- 실행 모드의 `LOMAssistant*` 디렉터리 **150개 C# 파일**을 훑었습니다. 설치 프로그램과 검사 도구 자체는 실행 UI 집계에서 제외합니다.
- 덧붙이기·보간·`string.Format`·`string.Join`·`StringBuilder` 조립식 **790개**를 수집했습니다. 자동 분류로 로그 225개, 한국어 분기 바깥의 원문 처리 48개가 포함됩니다. 이 수치는 미번역 화면 수가 아닙니다.
- 숫자·한국어 제목을 대입한 합성 조합 528개 중 잔존 후보는 **92개 조립식**입니다. 로그용 변수, 중국어 원문 자료, 실제로는 한국어 분기에서 사용하지 않는 코드 등도 남아 있어 92개를 실제 UI 오류 수로 볼 수 없습니다.
- 소스 사용처를 직접 확인한 **31개 구체 조합**을 실행했습니다. 현재 표시 처리에서 중국어가 남는 11개 조합, 번역 처리를 우회하는 게임 대사 2개를 확인했습니다. 이들은 아래 몇 가지 공통 원인에 묶이며 전체 누락 개수는 아닙니다.
- 잔존으로 집계된 나머지 2개는 원작 설치 프로그램의 실제 중국어 파일명과 ko.1의 과거 점프 오류 재현입니다. 현재 누락으로 분류하지 않았습니다.

원시 결과: [구체 표시 조합 TSV](chinese-composition-display-probes-3.2.1-ko.2.tsv). 자동 후보·전체 조립식은 검사 후 `bin/ko-check/chinese-composition-candidates.tsv`, `chinese-compositions.json`, `chinese-composition-summary.json`에 생성됩니다.

## 기존에 알려진 동적 자료

F9 플래그 전체 설명의 한중 혼합 **47건**을 다시 확인했습니다. 첫 줄 이름과 전체 값별 설명은 별개입니다. 이름 1,069개 ID 조회, 기존 표시 조합 5,304건, 캐시 조건 5,060건 검사 통과가 이 47건의 해결을 뜻하지 않습니다.

한국어 AI 경로는 직접 구성한 지시문·배경·도구 설명을 사용합니다. 파일에 남은 중국어 인물 배경이나 원본 도구 스키마를 모두 한국어 입력 누락으로 집계하지 않았습니다. 게임 대사·새 동적 자료·이전 채팅 기록 및 외부 모델 답변은 정적 점검만으로 한국어를 보장할 수 없습니다.

## 확인한 조합에서 정상인 부분

- ko.2에서 직접 생성하도록 바꾼 점프 제한 안내 5종. 과거 ko.1 방식은 같은 긴 제목을 넣으면 중국어가 남는 것도 재현했습니다.
- 점프 제목·임무명·주의문·기존 인연 관련 경고·분기 목적지의 대표 조합.
- 저장 화면의 빈 슬롯 안내·저장 상세·퀵세이브 불러오기 진행 안내.
- 비급 수련 점수 안내의 대표 조합. 합성 후보에 올라왔어도 실제 숫자를 넣으면 번역되는 경우는 누락으로 확정하지 않았습니다.
- 결투 적 행동 예측의 세로 배치.
- 플래그 변화 팝업과 기존 스토리/AI 직접 생성 경로는 기존 DLL·소스 검사를 유지했습니다.

## 재실행과 검증 한계

`tools/ko-check/run.ps1` 실행 시 기존 검사 뒤에 전체 조립식 목록과 구체 조합 결과를 생성합니다. 빌드된 DLL을 검사할 때는 `-ModAssembly bin/LOMAssistant.dll`, 실제 자료 재검사에는 기존 `-GameFlags`·`-LiveConditions` 인자를 함께 사용합니다.

기존 자동 검사 **9,119건 통과**. 새 조립식 점검은 문제를 찾기 위한 감사 출력이며, 잔존 후보가 있다고 기존 기능 검사를 실패시키지는 않습니다. 또한 31개 구체 조합은 전체 게임 상태의 실행 검증을 대체하지 않습니다. 화면 비율·배치·게임 판정·저장 형식·API 전송 코드는 이번 검사 작업에서 변경하지 않았습니다.

후속 수정은 랜덤 분기·결투 가로 표시·비급 보너스·설정 경고·퀵세이브 메모·게임 대사를 한국어 문구 키 또는 명시적 표시 변환에 연결한 뒤, 동일 조합이 한국어로 바뀌는지 검사하는 순서가 적절합니다. F9 전체 설명 47건은 값별 의미를 대조하는 별도 검수가 필요합니다.
